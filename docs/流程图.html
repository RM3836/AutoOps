⚡ AutoOps 自动化运维流程

1
🚀 系统启动
初始化数据库(4张表) → 启动Flask服务 → 启动后台监控线程 → 配置logging文件
▼
2
📊 自动采集服务器状态
psutil 每2秒采集 CPU / 内存 / 磁盘 / 网络 / 进程 → 写入 server_status 表
▼
3
🔍 阈值异常检测
CPU > 80% / 内存 > 85% / 磁盘 > 90% → 超标？
✅ 正常 → 继续监控（回到步骤2）
⚠️ 超标 → 触发告警流程
▼
4
🔔 自动告警
写入 alerts 表 → Web告警中心展示 → CRITICAL级别发送邮件通知
▼
5
🛡️ 安全日志分析（独立流程）
读取 auth.log → 关键词匹配(Failed password/OOM/segfault) → 正则提取攻击源IP → 按IP聚合统计
▼
6
🔍 暴力破解判定
单IP失败次数 ≥ 5 → 判定为暴力破解攻击？
✅ 低于阈值 → 标记为WARNING
🚨 暴力破解 → 标记为CRITICAL
▼
7
👤 管理员响应
仪表盘查看状态 → 服务器详情排查 → SSH远程登录 → 执行修复命令
▼
8
📝 操作记录 & 报告导出
SSH操作记录到 operation_logs → 导出HTML巡检报告 / CSV监控数据
AutoOps 运维闭环：采集 → 分析 → 告警 → 安全检测 → 响应 → 记录 → 报告
