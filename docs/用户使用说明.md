# AutoOps 用户使用说明

## 一、功能清单

| 页面 | 功能 | 说明 |
|------|------|------|
| 仪表盘 | 实时监控 | CPU/内存/磁盘实时数据+趋势图+进程列表 |
| 服务器 | 硬件详情 | CPU型号/核心、内存Buffers/Cache、磁盘分区/Inode、网卡流量、磁盘IO |
| SSH运维 | 远程管理 | 添加服务器、执行Linux命令、密钥认证 |
| 日志分析 | 安全检测 | 运行日志、认证日志分析、暴力破解检测、IP聚合统计 |
| 告警中心 | 告警管理 | 查看告警统计、告警记录、告警级别分类 |
| 工具箱 | 运维工具 | 主机扫描、并行端口扫描、DNS(A/MX/NS)、进程管理、HTML报告/CSV导出 |

## 二、操作步骤

### 2.1 启动系统
1. 打开终端/命令提示符
2. 进入项目目录：`cd AutoOps`
3. 执行启动命令：`python run.py`
4. 浏览器访问：启动日志里显示的地址
5. 系统启动后会自动初始化 SQLite 数据库，并通过 schedule 在后台定时采集监控数据

### 2.2 查看系统监控
1. 打开首页仪表盘
2. 页面自动刷新数据，其中状态卡片约每2秒更新一次，进程列表每5秒刷新一次
3. 查看CPU/内存/磁盘使用率（进度条+数字）
4. 查看实时趋势图表
5. 查看Top进程列表

### 2.3 SSH远程运维
1. 点击导航栏"SSH运维"
2. 点击"+ 添加"按钮，填写服务器信息（IP/端口/用户名/密码）
3. 在左侧服务器列表点击选择服务器
4. 在底部输入框输入Linux命令（如 `df -h`）
5. 或点击右侧快捷命令按钮（df -h / free -m / top等）
6. 查看命令执行结果

### 2.4 日志分析
1. 点击导航栏"日志分析"
2. 左侧查看平台运行日志（自动刷新）
3. 点击"分析日志"按钮执行安全检测
4. 右侧查看安全分析结果（可疑事件数量）
5. 查看日志统计图表

### 2.5 告警中心
1. 点击导航栏"告警中心"
2. 顶部查看告警统计（严重/警告/信息/已处理）
3. 下方查看告警记录列表
4. 点击"刷新"按钮更新数据

### 2.6 运维工具箱
1. 点击导航栏"工具箱"
2. **主机扫描**：选择模式（手动输入/子网扫描），点击开始扫描
3. **端口扫描**：输入目标主机和端口，点击扫描
4. **DNS解析**：输入域名，点击解析
5. **进程管理**：查看进程列表，可按CPU/内存排序，可终止进程
6. **报告导出**：点击生成HTML报告或导出CSV数据

## 三、常见问题与解决方案

### Q1: 启动报错 "ModuleNotFoundError"
**原因**：Python依赖未安装
**解决**：执行 `pip install -r requirements.txt`

### Q2: 页面显示空白或加载失败
**原因**：Flask服务未启动或端口被占用
**解决**：
1. 检查终端是否显示 "Running on http://0.0.0.0:5000"
2. 更换端口：修改 `config/settings.py` 中的 `PORT` 值
3. 关闭占用5000端口的程序

### Q3: SSH连接失败
**原因**：目标服务器SSH服务未开启或网络不通
**解决**：
1. 确认目标服务器已安装并启动SSH服务：`systemctl status sshd`
2. 确认网络连通：`ping 目标IP`
3. 检查防火墙是否放行22端口

### Q4: 告警不触发
**原因**：CPU/内存未超过阈值
**解决**：
1. 查看阈值配置：`config/settings.py` 中的 CPU_THRESHOLD 等
2. 手动制造高负载测试：终端执行 `yes > /dev/null &`
3. 测试完关闭：`killall yes`
4. Windows 可用 PowerShell 执行 `while ($true) { 1..100000 | % { [math]::Sqrt($_) } }`，测试后按 `Ctrl+C` 停止

### Q5: 数据库报错
**原因**：数据库文件损坏或被删除
**解决**：删除 `database/autoops.db` 后重新启动，系统会自动重建

### Q6: 工具箱扫描结果为空
**原因**：输入的IP不可达或防火墙拦截
**解决**：
1. 先用 `127.0.0.1` 测试本机扫描
2. 确认目标主机在同一网段
3. 检查防火墙设置

## 四、截图建议

答辩或验收时建议按顺序截图：

1. 首页仪表盘：实时状态卡片、趋势图、Top进程
2. SSH运维：服务器添加区域和命令执行结果
3. 日志分析：日志列表和安全分析结果
4. 告警中心：告警统计和告警表格
5. 工具箱：主机扫描、端口扫描或报告导出结果
